# 🏀 NBA History - On This Day

A beautiful, interactive web application that displays NBA historical facts in an "On This Day" format. Discover legendary moments, record-breaking performances, and significant milestones in basketball history.

## ✨ Features

- **Daily NBA Facts**: Automatically shows NBA historical events for the current date
- **Interactive Date Navigation**: Explore any date to discover NBA history
- **Random Fact Generator**: Get surprised with random legendary NBA moments
- **Modern UI Design**: Sleek glassmorphism design with NBA-themed colors
- **Fully Responsive**: Works perfectly on desktop, tablet, and mobile devices
- **Zero Dependencies**: Pure HTML, CSS, and JavaScript - no frameworks needed

## 🚀 Demo

Simply open `index.html` in your web browser to start exploring NBA history!

## 🎯 How to Use

1. **Today's Fact**: The app automatically loads with today's NBA historical fact
2. **Random Facts**: Click "Random Fact" to discover a surprise NBA moment
3. **Date Explorer**: Use the date picker to explore specific dates in NBA history
4. **Navigate**: Click "Today's Fact" to return to the current date

## 🛠️ Installation & Setup

### Option 1: Direct Download
1. Download or clone this repository
2. Open `index.html` in your preferred web browser
3. Start exploring NBA history!

### Option 2: Local Server (Optional)
```bash
# If you prefer running on a local server
python -m http.server 8000
# OR
npx serve .
```

Then navigate to `http://localhost:8000`

### Adding New Facts

To add new NBA facts, edit the `nbaFacts` object in `index.html`:

```javascript
const nbaFacts = {
    "month-day": "Your amazing NBA fact here...",
    // Example:
    "1-24": "On January 24, 2006, Kobe Bryant scored 81 points..."
};
```
